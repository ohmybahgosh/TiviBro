# TiviBro for the Homebrew Channel

Add one of these in the Homebrew Channel settings:

- `https://raw.githubusercontent.com/ohmybahgosh/TiviBro/homebrew/repo.json`: releases
- `https://raw.githubusercontent.com/ohmybahgosh/TiviBro/homebrew/repo-testing.json`: every build, including test builds

On a rooted TV, over SSH: `curl -fsSL https://raw.githubusercontent.com/ohmybahgosh/TiviBro/homebrew/install.sh | sh`

Written by the Release workflow; do not edit by hand.
