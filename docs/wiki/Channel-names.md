*Web editor: the web editor*

Rules strip clutter from every name at once: country prefixes like `US |`, quality tags like `FHD`, brackets and more.  Add your own prefixes and suffixes, and preview each name before and after.  Your provider's names are untouched, so switching a rule off brings the original back.  Names you set by hand stay.
